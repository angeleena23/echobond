# ECHOBOND 🤝
### A promise spoken. A record remembered.

**The problem**

Many daily-wage workers make verbal agreements with employers about the type of work, number of days, daily wages, advances and payment dates. These details can be forgotten or misunderstood, making it difficult to track how much payment is still due.

**Our solution**

ECHOBOND is a voice-based work agreement and payment tracker designed to help workers maintain a personal record of their work arrangements. It converts spoken agreements into editable text and provides a simple wage calculator to track expected and received payments.

**How it works**

1. **Speak:** The user uploads an audio recording of a verbal work agreement.
2. **Transcribe:** Gnani AI speech-to-text converts the recording into text.
3. **Review:** The user checks and edits the transcript to correct any recognition errors.
4. **Save:** The user saves the agreement record.
5. **Calculate:** The payment calculator uses work days, daily wages, advances and payments received to estimate the remaining amount.

**Technology used**

- Gnani AI Speech-to-Text API
- Python
- Streamlit
- Requests and Python dotenv

**Expected impact**

ECHOBOND aims to make everyday work agreements easier to remember and payment calculations easier to understand. It focuses on accessibility through voice input and a simple interface, especially for people who may find written record-keeping difficult.

**Current status**

ECHOBOND is a working prototype with audio transcription, editable agreement records and a payment calculator. Users are encouraged to verify the generated transcript before saving, as speech recognition can make mistakes.

**Important:** ECHOBOND is a personal record-keeping tool, not legal proof or a substitute for a written contract.
